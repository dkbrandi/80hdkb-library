# 80hdkb Library

An Android app for cataloguing the Brandi home library: covers, titles, authors, genres, pages, reading status, and the room and shelf each book lives on. Works offline and syncs through the Home Library Google Sheet.

- **Install and setup:** see [SETUP.md](SETUP.md)
- **Latest APK:** [Releases](../../releases/latest)
- **App interface:** `app/src/main/assets/www`
- **Android shell:** `app/src/main/java`
- **Sheet sync script:** `sheet-sync/Code.gs`

Every push to `main` builds a signed APK on GitHub Actions and publishes it as a new release.
